Under the hood

One model call, then code has the last word

  1. Extract. Gemini 3.5 Flash-Lite (temperature 0, JSON-schema output) reads the message as data and returns category, payment type, amount, date, payee and a draft reply. The rules sheet is the only source it may quote.
  2. Compute. Code, not the model, works out the deadline (T+1 for people, T+5 for shops), whether it has passed, the rules that apply and where to escalate.
  3. Verify. A validator rejects replies that contradict those facts, invent days, links or phone numbers, or ask for a PIN. It retries once with the verified facts, then falls back to a safe template.
  4. Protect. The key sits in a Cloudflare Worker. Only this site can call it, input is capped at 1,500 characters, each visitor gets 5 tries a minute and there's a daily cap. If the live model is busy, the page shows a recorded response instead.

Evaluated on 50 synthetic cases (20 held out): 100% classification and correct rule, 0% hallucinated rules, 0% unsafe advice. Latency is the open problem on the free tier. Not legal or financial advice; “Lumo Pay” is fictional.
